
# PADOC AI LOCAL LLM

Agora a PADOC possui um motor de linguagem local.

Arquitetura:

brain/
- modelo_ia.py
- modelo GGUF local

A IA:
- interpreta perguntas
- raciocina
- usa conhecimento automotivo
- responde como especialista

Sem ChatGPT API.

Executar:

pip install -r requirements.txt

python app.py


Evoluções:
- treinamento próprio PADOC
- visão computacional
- OBD2
- app mobile
- dashboard
